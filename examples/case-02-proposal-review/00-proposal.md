## 받은 제안서 (요약)

**「생산·재고 통합 가시화 플랫폼 구축 제안」**

### 제안 개요

> 귀사의 생산 실적과 재고 데이터를 통합 수집하여 경영진이 실시간으로
> 확인할 수 있는 대시보드를 구축합니다.

### 기대 효과

| 항목 | 제시된 수치 |
|---|---|
| 재고 감축 | **동종 사례 평균 22 %** |
| 실적 집계 시간 | 일 2시간 → **10분** |
| 투자 회수 | **6개월 이내** |

> 당사는 제조업 유사 구축 **12건**의 경험을 보유하고 있습니다.

### 사업 금액

| | |
|---|---|
| 구축비 | 4억 2,000만원 |
| 연 유지보수 | 8,000만원 |
| 기간 | 5개월 |

### 추진 일정

```
1개월차  요구사항 정의
2~4개월차 개발 및 데이터 연계
5개월차  안정화 및 이관
```

### 제안서에 적힌 전제

> - 귀사 ERP에서 데이터 추출이 가능해야 합니다
> - 담당자 지정이 필요합니다
