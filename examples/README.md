# 예시

실제로 돌려본 결과를 그대로 담았다. 읽기만 해도 이 도구가 무엇을 내놓는지 알 수 있다.

> ## ⚠️ 모든 예시는 가공 데이터다
>
> 회사명·수치·채용공고·기사 모두 예시를 위해 지어낸 것이다.
> 실재하는 어떤 기업과도 관계가 없다.
>
> 실제 사례를 쓰지 않은 이유가 있다. 이 프로젝트는 탈식별화를 규칙으로 삼는데,
> 예시에 실제 회사를 쓰면 그 규칙을 스스로 어기는 셈이 된다.

## case-01 · 자동차 부품 2차 협력사 (모드 A)

| 파일 | 내용 |
|---|---|
| [`00-signals.md`](case-01-precision-parts/00-signals.md) | 입력 신호 — 채용공고 5건, 뉴스 4건, 감사보고서 요약 |
| [`01-analysis.md`](case-01-precision-parts/01-analysis.md) | 전체 산출 — S1~S9, 임기 게이트, 반박 안내 |
| [`02-artifacts.md`](case-01-precision-parts/02-artifacts.md) | 회사 카드와 원장 항목, 탈식별화 성공·실패 대조 |

### 이 예시에서 볼 만한 것

**뻔한 답 게이트가 실제로 무엇을 걸러내는가**

> 뻔한 답: 마진이 떨어졌으니 원가를 절감해야 한다. → 버림
> 실제 답: 마진 하락이 원가가 아니라 **재고와 감가상각**으로 더 잘 설명된다.

원가절감과 운전자본은 제안 방향이 완전히 다르다. 게이트가 없으면 첫 번째 답에서 멈춘다.

**"안 넣으면 누가 곤란해지는가"가 제안을 하나 막는다**

견적 업무는 자동화 후보처럼 보인다. 그런데 담당자를 이제 뽑는 중이라
지금은 아무도 그 데이터를 안 본다. **넣어도 안 쓰인다.**
그래서 이 예시의 가설 H3은 **팔지 않기 위한 가설**이다.

**임기 게이트가 "포기"가 아니라 "결정권을 올려라"로 이어진다**

만날 사람은 잔여 임기가 짧아 회수 1.5년짜리 안건이 막힌다.
그런데 회사는 오너 경영이고 대표는 시야가 길다.
→ 같은 안건이 **대표 레벨에서는 살아난다.** 게이트의 쓰임이 여기서 드러난다.

**탈식별화 성공과 실패를 나란히 보여준다**

`02-artifacts.md` 에 못 올릴 항목과 고쳐 쓴 항목을 같이 실었다.
숫자를 관계로 바꾸면 회사가 사라지고 조건만 남는데, 오히려 더 넓게 쓸 수 있는 항목이 된다.

## 이 예시로 확인된 규칙 준수

| 규칙 | 결과 |
|---|---|
| 등급 없는 문장 금지 | 지켜짐 |
| `[가설]`에 반증 조건 | 지켜짐 |
| S2~S6 뻔한 답 게이트 | S2·S3·S5에서 작동. S4·S6은 표 형식이라 생략 → **개선 필요** |
| `[불가]` 판정 존재 | 2건 (시기상조 1, 역량 밖 1) |
| 임기 게이트 전부 통과 금지 | 통과 1 · 탈락 2 |
| "남은 모름" 비우지 않기 | 7건. 그중 2건은 "포기"로 명시 |
| 반박 안내 | 약한 고리 3개 + 전체가 흔들리는 조건 + 못 본 관점 |

### 돌려보고 알게 된 것

예시를 만드는 것 자체가 시험이었다. 규칙의 빈틈 두 개가 실제로 드러났다.

- **S4·S6에서 뻔한 답 게이트를 건너뛰게 된다.** 그 두 단계는 표로 정리되는데,
  표 형식에는 "뻔한 답 → 버림" 을 끼워 넣을 자리가 없다.
  하필 S6이 개입 판정이라, 제일 뻔한 답이 나오기 쉬운 자리가 그냥 지나간다.
  → [#11](https://github.com/Kdreamtomaster/ax-commons/issues/11)
- 임기 게이트는 **"통과 / 탈락" 두 값보다 "누구 선에서 통과하느냐"** 가 실전에서 더 쓸모 있었다.
  case-01에서 같은 안건이 본부장 선에서는 막히고 대표 선에서는 살아났는데,
  지금 규칙으로는 그게 표현되지 않아 사람이 따로 덧붙여야 했다.
  → [#12](https://github.com/Kdreamtomaster/ax-commons/issues/12)

둘 다 이슈로 열어 두었다. **도구가 자기 빈틈을 스스로 드러낸 셈이고,
그게 이 저장소가 작동하는 방식이다.**
