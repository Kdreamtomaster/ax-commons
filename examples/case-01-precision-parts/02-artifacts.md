# 남기는 산출물 — 회사 카드와 원장 항목

> ⚠️ 가공 데이터 기반 예시다. 실재 기업과 무관하다.

대화가 끝나면 사라진다. 그래서 두 갈래로 나눠 사용자가 보관한다.

- **회사 카드** — 이 회사에만 해당. 기밀 포함 가능. 비공유
- **인사이트 원장** — 회사에 안 묶이는 배움만. 공유 가능

---

## 회사 카드 (복사해서 보관)

```markdown
# 회사 카드 · (주)예시정밀

갱신일: 2026-06-20   |   회차: 1

## 기본
- 자동차 부품 2차 협력사 / 매출 1,000억 안팎 / 오너 경영(2세 승계 완료)
- 만날 자리: 생산본부장(상무) · 재임 2년차 · 외부 영입 · 잔여 임기 추정 1년 [가설]

## 목적함수 (추정)
- 극대화: 증설 투자 성과 증명  [가설]
  근거: 투자 결정 2025-03(전임 회장 시절), 승계 2026-02, 아직 성과 미확인
- 방어:   고객 2곳 68 % 의존의 변동성  [추론]
  근거: 매출처 집중 주석 + 2026-06 업계 물량 축소 기사
- 대안 가설: 매각 준비  ← 아직 안 버림. 증설 후 매각은 흔한 경로다

## 확인된 병목
| 병목 | 등급 | 근거 | 개입 판정 | 임기 게이트 |
|---|---|---|---|---|
| 재고 회전 악화 | [사실] | 재고 88→131억, 매출 −4 % | 저감 | 후임자 리스크 |
| 생산실적 수기 집계 | [사실] | 채용공고 업무 기술 | 저감 | 통과 |
| 견적 프로세스 부재 | [추론] | 신설 공고 | 불가(시기상조) | 탈락 |

## 기각된 가설
| 가설 | 언제 | 왜 |
|---|---|---|
| (아직 없음 — 1회차) | | |
※ 이 칸을 비워 두지 않는다. 미팅 후 반드시 채운다.

## 약속하지 않을 것
- 견적 자동화  ← 프로세스 부재. 지금 팔면 도입 후 안 쓰인다
- 설비 데이터 수집(PLC/MES)  ← 우리 지원 범위 밖
- 재고 예측의 정확도 수치  ← 데이터 품질을 못 봤다

## 다음에 확인할 것
| 모르는 것 | 어떻게 | 누구에게 |
|---|---|---|
| 재고 증가가 의도된 것인지 | H1 반증 질문 | 생산본부장 |
| 본부장 실제 재임·재계약 | 대화 중 자연스럽게 | 본인 |
| 물량 축소 기사 해당 여부 | 우회 질문 | 본부장 |
| 증설 차입금 상환 일정 | 재무 라인 접촉 시 | 미정 |

## 기밀 표시
- (1회차라 아직 없음. 미팅에서 들은 내부 사정은 여기에만 적는다)
```

## 인사이트 원장에 올릴 항목

미팅 **전**이라 아직 검증되지 않았다. 그래도 형식은 갖춰 둔다.

### 후보 1 — 올릴 수 있다

```markdown
## 신설 직무는 자동화 대상이 아니다

- 조건: 해당 업무를 전담하는 자리가 최근에 신설되었고, 아직 채용이 끝나지 않은 상태
- 관찰: 그 업무를 자동화하자고 제안하면 도입 후에 쓰이지 않는다
- 메커니즘: 자동화는 기존 프로세스를 옮기는 일이다.
  신설 직무는 프로세스가 아직 정해지지 않아서 옮길 대상이 없다.
  게다가 그 자리에 올 사람이 자기 방식을 정하기 전이라,
  먼저 만든 도구는 그 사람의 방식과 어긋날 확률이 높다.
- 전이 범위: 신설 직무 한정. 기존 담당자가 있는 업무에는 적용 안 됨
- 반증 조건: 신설 직무인데도 표준 템플릿이 이미 있고, 도입 후 6개월 이상 쓰인 사례
- 검증: [1회, 미검증]
- 출처 건수: 1건
- 관찰 시점: 2026-06 / 유효기간 추정: 60개월 (사람의 행동 방식에 의존)
- 반례: 없음
- 원 출처: 자체 관찰
```

**탈식별화 점검** — "이 문장만 보고 어느 회사인지 좁혀지는가?"
→ 산업·규모·회사 특징이 전혀 없다. **통과.**

### 후보 2 — 올릴 수 없다 (예시)

```markdown
## 매출 1,000억 자동차 부품 2차사가 200억 증설 후 마진이 2.4 %로 떨어졌다
```

**탈식별화 점검** → **탈락.**
산업 + 규모 + 투자액 + 마진이 한 문장에 있다. 업계 사람이면 후보가 몇 곳으로 좁혀진다.

**고쳐 쓰면 이렇게 된다.**

```markdown
## 물량 전제 증설은 물량이 안 오면 마진을 두 배로 깎는다

- 조건: 단가 결정권이 없는 수탁 제조. 증설 직후 매출이 정체하거나 감소
- 관찰: 감가상각과 재고가 동시에 늘면서 영업이익률이 예상보다 크게 빠진다
- 메커니즘: 단가를 못 올리는 구조에서는 고정비 증가를 판가로 흡수할 수 없다.
  게다가 증설은 생산능력을 먼저 늘리므로 재고가 앞서 쌓인다. 두 효과가 겹친다.
- 전이 범위: 단가 결정권이 없는 수탁 제조 한정. 자체 브랜드 제조에는 적용 안 됨
- 반증 조건: 같은 조건에서 증설 후 마진이 유지되거나 개선된 사례
- 검증: [1회, 미검증]
- 관찰 시점: 2026-06 / 유효기간 추정: 36개월 (시장 구조 의존)
```

**숫자를 관계로 바꾸니 회사가 사라지고 조건만 남았다.**
그리고 오히려 더 넓게 쓸 수 있는 항목이 됐다.
