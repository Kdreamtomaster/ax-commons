## 4. 산업 참조값

`tuning.md` 의 `margin_reference` 에 채워 넣은 값이라고 가정한다.

```yaml
- industry: "자동차 부품 2차 협력사"
  year: "2025"
  source: "(예시용 가공값 — 실제 통계 아님)"
  operating_margin:
    top: "7~9 %"
    median: "4~5 %"
    bottom: "1~2 %"
  swing_factors: ["견적 리드타임", "재고 회전율", "불량 재작업률"]
```

## 이 예시가 시험하려는 것

| 규칙 | 왜 이 데이터로 확인되는가 |
|---|---|
| 뻔한 답 게이트 | "마진이 떨어지니 원가절감이 필요하다"가 뻔한 답으로 나오기 딱 좋다 |
| `[불가]` 판정 필수 | 설비 제어는 우리가 못 하는 영역이라 반드시 하나는 나온다 |
| 임기 게이트 | **오너(2세)와 전문경영 임원의 시야가 다르다.** 섞여 있어야 게이트가 갈린다 |
| 남은 모름 | 승계 진행 정도, 물량 축소 대상 여부는 밖에서 알 수 없다 |
| 부재 신호 | 설비보전 공고가 사라진 것을 잡아내는지 |
